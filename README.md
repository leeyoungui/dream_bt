# 드림호 웹 블루투스 보드게임 (Dream BT)

마이크로비트를 **웹 블루투스 컨트롤러**로 쓰는 수업용 우주 보드게임입니다.
원본 수동 조작판 [`leeyoungui/dream`](https://github.com/leeyoungui/dream)의 디자인과 규칙을 그대로 계승하고, 블루투스 통신만 더했습니다. 원본 저장소는 건드리지 않았습니다.

- 게임 주소: **https://leeyoungui.github.io/dream-bt/**
- 대상: 중학교 3학년 (2차시 연강 가능)
- 브라우저: 크롬 · 엣지 · 웨일 (사파리·iOS는 웹 블루투스 미지원)

## 무엇이 들어 있나

| 파일 | 설명 |
| --- | --- |
| `index.html` | 게임 본체 (단일 파일, 외부 라이브러리 없음) |
| `microbit/dream_bt_microbit.js` | 마이크로비트 MakeCode 송신 코드 |

## 게임 규칙

- 30칸 뱀 모양 보드, 1번 지구 → 30번 새 행성. 먼저 도착한 팀 승리.
- 9가지 이벤트: +3 연료(3), -3 운석(7), 쉬기·산소(10), +4 태양풍(13), -2 궤도(16), 한 번 더(19), +3 동료(22), -4 블랙홀(25), 쉬기·엔진(28).
- 위기 칸(운석·궤도 이탈·블랙홀) → **A버튼 방어막** 성공 시 피해 면제
- 회복 칸(산소 부족·엔진 고장) → **5번 흔들기** 성공 시 쉬지 않고 계속
- 블루투스가 끊기거나 기기가 없으면 화면의 **수동 주사위 / 성공 / 실패** 버튼으로 그대로 진행합니다.

## 신호 약속

| 마이크로비트 조작 | 문자열 | 웹 화면 반응 |
| --- | --- | --- |
| A+B 버튼 | `DICE:1` ~ `DICE:6` (또는 `DICE`) | 그 수만큼 자동 전진 |
| 흔들기 ×5 | `SHAKE` | 흔들기 0/5 → 5/5 자동 카운트, 성공 판정 |
| A 버튼 | `SHIELD` (또는 `A`) | 방어막 성공 판정 |

## 통신 사양 (Nordic UART Service)

| 항목 | UUID |
| --- | --- |
| Service | `6e400001-b5a3-f393-e0a9-e50e24dcca9e` |
| TX (웹 → 마이크로비트) | `6e400002-b5a3-f393-e0a9-e50e24dcca9e` |
| RX (마이크로비트 → 웹) | `6e400003-b5a3-f393-e0a9-e50e24dcca9e` |

- 수신은 `RX` 캐릭터리스틱의 notification으로 받습니다.
- 마이크로비트가 줄바꿈 없이 `DICE:4SHAKE`처럼 붙여 보내도 되도록, 웹 쪽은 알려진 명령 토큰을 앞에서부터 찾아 잘라 내는 파서를 씁니다.

## 마이크로비트 준비

1. `makecode.microbit.org` → 새 프로젝트
2. 고급(Advanced) → 확장(Extensions) → `bluetooth` 검색 → **Bluetooth** 추가 (radio 확장은 제거됩니다)
3. ⚙ → 프로젝트 설정 → **No Pairing Required: Anyone can connect via Bluetooth** 켜고 저장
4. `microbit/dream_bt_microbit.js` 코드를 넣거나 블록으로 조립 → **다운로드** → `MICROBIT` 드라이브로 끌어다 놓기
5. 웃는 얼굴이 나오면 준비 완료
