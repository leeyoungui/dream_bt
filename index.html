드림호가 새 행성에 무사히 도착했습니다! 🪐

🎓 마이크로비트 코딩 가이드

메이크코드(MakeCode)에서 블루투스 신호를 보내는 코드를 10~15분 안에 완성합니다. · 중학교 3학년

0준비물 확인

  • 마이크로비트(가급적 V2) + USB 케이블 또는 배터리팩
  • 크롬(Chrome)·엣지·웨일 브라우저가 설치된 노트북/크롬북 (사파리·아이폰은 웹 블루투스 미지원)
  • makecode.microbit.org 접속

1블루투스 확장 프로그램 추가

  1. MakeCode에서 새 프로젝트를 만듭니다.
  2. 블록 목록 아래 고급(Advanced) → 확장(Extensions)을 누릅니다.
  3. bluetooth를 검색해 Bluetooth 확장을 추가합니다.
  4. “radio 확장이 제거됩니다”라는 안내가 나오면 확장 제거 후 Bluetooth 추가를 누릅니다. (이 프로젝트에만 적용)

2페어링 없이 연결되게 설정 (핵심 꿀팁)

  1. 오른쪽 위 ⚙ 톱니바퀴 → 프로젝트 설정(Project Settings)을 엽니다.
  2. No Pairing Required: Anyone can connect via Bluetooth를 켭니다.
  3. 저장(Save)을 누릅니다.

이 설정을 켜지 않으면 브라우저에서 연결할 때 PIN·패턴 입력 창이 떠서 수업이 자주 멈춥니다. 프로젝트마다 따로 설정해야 하니 새 프로젝트를 만들 때마다 확인하세요.

3블록 코딩 ① 시작 · A+B 버튼 = 주사위

시작하면 (on start)

블루투스 UART 서비스를 시작합니다. → bluetooth start uart service

A+B 버튼을 누르면

1~6 중 무작위 수를 골라 DICE: 뒤에 붙여 문자열로 보냅니다.

보내는 블록

bluetooth uart write string에 join("DICE:", pick random 1 to 6)을 넣습니다.

4블록 코딩 ② 흔들기 = 위기 탈출

흔들면 (on shake)

SHAKE 문자열을 보냅니다. → 웹 화면이 흔들기 횟수를 5번까지 자동으로 셉니다.

5블록 코딩 ③ A버튼 = 에너지 방어막

A 버튼을 누르면

SHIELD 문자열을 보냅니다. → 운석·블랙홀 칸에서 피해를 막습니다.

6전체 코드 (JavaScript 탭에 붙여넣기)

블록으로 조립한 뒤 JavaScript 탭을 열면 아래와 같은 코드가 됩니다. 급할 때는 이 코드를 그대로 붙여넣어도 됩니다.

bluetooth.startUartService()

input.onButtonPressed(Button.AB, function () {
    bluetooth.uartWriteString("DICE:" + randint(1, 6))
})

input.onGesture(Gesture.Shake, function () {
    bluetooth.uartWriteString("SHAKE")
})

input.onButtonPressed(Button.A, function () {
    bluetooth.uartWriteString("SHIELD")
})

bluetooth.onBluetoothConnected(function () {
    basic.showIcon(IconNames.Yes)
})

bluetooth.onBluetoothDisconnected(function () {
    basic.showIcon(IconNames.No)
})

7마이크로비트에 넣기

  1. USB 케이블로 마이크로비트를 컴퓨터에 연결합니다(드라이브 MICROBIT이 보이면 성공).
  2. 다운로드를 눌러 .hex 파일을 받습니다.
  3. MICROBIT 드라이브로 파일을 끌어다 놓습니다. 노란 불이 깜빡인 뒤 웃는 얼굴이 나오면 완료!

8웹 화면과 연결하기

  1. 브라우저에서 https://leeyoungui.github.io/dream_bt/ 를 엽니다.
  2. 오른쪽 위 📡 마이크로비트 블루투스 연결을 누릅니다.
  3. 목록에서 BBC micro:bit [내 기기 이름]을 고릅니다.
  4. 배지가 초록색 연결됨으로 바뀌면 성공! A+B를 눌러 주사위를 시험해 봅니다.

9신호 약속표

마이크로비트 조작보내는 문자열웹 화면 반응
A+B 버튼DICE:1 ~ DICE:6그 수만큼 우주선이 자동으로 전진
흔들기 ×5SHAKE산소 부족·엔진 고장 칸에서 5회 세고 성공 판정

!연결이 안 될 때

  • 기기가 안 보여요 → 다른 앱/태블릿이 이미 그 마이크로비트에 연결되어 있지 않은지 확인하고, 그 연결을 해제합니다.
  • 연결은 되는데 반응이 없어요 → “시작하면 UART 서비스 시작” 블록을 넣었는지, 코드를 다시 다운로드했는지 확인합니다.
  • PIN 창이 떠요 → 프로젝트 설정의 No Pairing Required를 켜고 다시 다운로드합니다.
  • 수업이 급해요 → 화면의 수동 주사위 / 성공 / 실패 버튼으로 그대로 진행할 수 있습니다.
